# YabosClothTool

YabosClothTool is a fork of [grzyClothTool](https://github.com/grzybeek/grzyClothTool) by [grzybeek](https://github.com/grzybeek).

The original project is an open-source tool for creating and managing GTA V addon clothing packs.

## Purpose of this fork

This fork is intended to experiment with features useful for RAGE:MP clothing workflows, especially:

- faster clothing preview workflow
- automatic component preview
- batch screenshot/export ideas
- cleaner CDN-ready clothing image generation
- easier handling of drawable/texture previews
