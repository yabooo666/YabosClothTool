# YabosClothTool

YabosClothTool is a dark, focused clothing asset workflow tool.

The interface is branded around a premium black and neon red visual direction.

## Focus

- clothing project setup and management
- drawable and texture organization
- preview-assisted iteration
- build/export workflow support
